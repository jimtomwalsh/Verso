Verso UI kit

Live canonical control primitives, rendered from the real editor source (src/editor.js → window.__kit) — not copied markup. Change a primitive and it changes here. Editor chrome is dark-only by design (design-system/readme.md).

What this is

  • The single source of truth for every editor control. Compose panels from these — never hand-roll markup that duplicates one.
  • Each primitive is shown in a representative state. Interactions are live but write to nothing (the gallery has no document).
  • New in the kit as later tickets land: the collapsed-optional row (ticket 2) and the repeated-item row (ticket 3).
