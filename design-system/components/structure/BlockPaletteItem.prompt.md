**BlockPaletteItem** — a row in the Blocks palette (left panel). Leading type icon in a chip + block name. Click or drag onto the canvas to insert.

```jsx
<BlockPaletteItem icon="heading" label="Heading" />
<BlockPaletteItem icon="image" label="Image" />
<BlockPaletteItem icon="list-checks" label="Quiz (knowledge check)" />
```
